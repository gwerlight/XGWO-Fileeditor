# Sicherheitshinweise

## Sicherheitslücken melden

Bitte melde Sicherheitslücken **nicht** als öffentliches Issue, sondern vertraulich über
[Private Vulnerability Reporting](https://github.com/gwerlight/XGWO-Fileeditor/security/advisories/new)
(Reiter „Security“ → „Report a vulnerability“).

Hilfreich sind eine kurze Beschreibung, die betroffene Version und, wenn möglich, eine Beispieldatei oder Schritte zum
Nachvollziehen. Ich melde mich so bald wie möglich zurück und stimme mit dir ab, wann die Lücke veröffentlicht wird.

## Unterstützte Versionen

Gepflegt wird jeweils die neueste Version auf `main`.
